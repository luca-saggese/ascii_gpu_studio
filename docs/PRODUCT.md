# Product notes

The visual direction is a restrained dark creative tool with a quiet green accent and a wide canvas. The source and type controls are kept in a compact left inspector; the preview remains the primary surface. Mobile uses a two-tab preview/controls layout. Controls that are visible in this version are wired to the renderer; video controls only appear for a loaded video.

All processing stays in the browser. Export descriptions: `.ascii` preserves the source and settings; PNG is the current WebGL canvas; audio remains associated with video playback only and is not included in PNG or project rendering.
