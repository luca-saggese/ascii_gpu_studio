# Runtime API

`createAsciiRenderer({ canvas, scene, onError })` creates a WebGL2 renderer. `setSource(imageOrVideoElement)`, `setScene(scene)`, `resize()`, and `renderFrame()` update the canvas. `capturePng()` returns a PNG `Blob`; `getStats()` returns current cell dimensions and backend. `dispose()` releases GL resources.

Scene colors are CSS hex values. `grid.maxCells` caps total cells; `grid.columns` is accepted only for backwards compatibility and no longer determines output size. `typography.fontSize` is 4–16 logical px (default 8), `typography.lineHeight` is 0.8–1.5 (default 1), and `typography.charset` contains 2–128 codepoints. Brightness is -0.5–0.5, contrast is 0.4–1 (default 0.4), and gamma is positive. `edgeDetection.threshold` is 0–100 (default 1); `edgeDetection.smoothing` is 0–3 and defaults to 0 (off). Source must be decoded by the browser before passing it to the renderer.

The renderer additionally exposes `captureText()`, returning the plain-text grid, columns, rows, measured integer font-cell dimensions, final logical output dimensions, source/target dimensions, baseline, and optional per-cell source colors. These values are calculated by the same source-aware layout used by preview and all exports. The operation samples through Canvas 2D on demand and is intended for text preview/export rather than high-throughput video rendering.

The portable result model and gzip JSON reader/writer are implemented in `src/ascii-document.js`; `src/ascii-export.js` captures deterministic timestamped pages and optional audio; `src/ascii-render.js` renders PNGs from those pages. The exported HTML is generated by `src/templates/playable-template.js` and decodes the same document format.

The Vue wrapper is exported from `packages/vue/src/index.js` as `AsciiPlayer`. It loads a legacy project URL or Blob, emits `ready`, `error`, `play`, `pause`, `timeupdate`, and `ended`, and exposes `play`, `pause`, `seek(seconds)`, and `capturePng()` through its component ref. It uses native video audio and the browser video clock.

```vue
<script setup>
import { ref } from 'vue';
import { AsciiPlayer } from '@ascii-gpu/vue';
const player = ref(null);
</script>
<template>
  <AsciiPlayer ref="player" src="/assets/demo.ascii" @ready="onReady" />
</template>
```
